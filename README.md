## 🕹️ How to Play

Use the **Arrow Keys** to control the snake and collect glowing food to increase your score.

| Key         | Action         |
| ----------- | -------------- |
| ⬆️ ⬇️ ⬅️ ➡️ | Move Snake     |
| `Space`     | Pause / Resume |
| `R`         | Restart        |

Avoid hitting the **walls** or the **snake's own body**.
